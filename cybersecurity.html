Journey

How I got into cybersecurity

My interest in cybersecurity began through curiosity. What started with simple terminal commands quickly evolved into a deeper interest in how systems work, how vulnerabilities are discovered and how attackers think.

Over time I began studying web application security, penetration testing, bug bounty methodologies and vulnerability research.

Today, cybersecurity is the area where I invest most of my learning efforts, combining practical testing, development and research.

Main Project

Synex

Offensive Security Platform

Synex is my largest cybersecurity project and serves as a platform for studying reconnaissance, vulnerability discovery, validation and security automation.

The project combines multiple offensive security workflows into a single platform capable of discovering assets, fingerprinting technologies, collecting evidence and validating findings.

One of the primary goals of Synex is reducing false positives by using contextual analysis and validation techniques instead of relying solely on traditional scanner signatures.
